# ДИКТАТУРА: Королевский указ

Minecraft Java 1.21.1 · NeoForge 21.1.172 · Java 21

## Сборка

Откройте проект в IntelliJ IDEA с установленной Java 21 либо запустите `gradle build`.

## Обновление

- Добавлен предмет «Королевский хлыст»: отдельная текстура и модель, 4 единицы урона (2 сердца), прочность 256 применений и собственный звук щелчка.
- В сцене позора яйца запускаются как настоящие снаряды от временно появляющихся жителей, а не выбрасываются как предметы.
- Попытка сломать блок на королевской территории отменяется и вызывает королевский патруль.
- Патруль очищает лошадь и обоих офицеров после доставки игрока, отмены погони или выхода игрока.
- Королевские покои остаются запретной зоной.

Предмет можно выдать командой `/give @s dictatorship:royal_whip`.
