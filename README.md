# ДИКТАТУРА — Королевский указ

Исходный проект мода для **Minecraft Java 1.21.1 + NeoForge 21.1.172 + Java 21**.

## Реализовано в исходниках текущего прототипа
- Компактный королевский комплекс рядом с точкой мирового спавна: тронный зал, сцена, тюрьма, казарма, стойка банка и простое колесо.
- 30 случайных указов. Новый указ выбирается раз в 120 секунд активной игры сервера; одновременно действует только один указ, предыдущий заменяется.
- Эффекты для ряда указов и проверка нарушений для части правил.
- При обнаружении нарушения появляется «офицерская карета» — лошадь с двумя NPC-офицерами. Она пытается добраться до нарушителя; затем начинается случайное наказание.
- Четыре варианта приговора: заключение на 30–200 секунд, сцена позора с летящими яйцами, колесо хомяка на 45 секунд или не-графическая игровая казнь (смерть персонажа и обычное возрождение Minecraft).
- Королевский банк с командами `/bank balance`, `/bank invest <amount>` и `/bank withdraw`.
- Банковские счета сохраняются в данных мира. Каждые 5 минут банк либо лопается (30% шанс, вклады сгорают), либо начисляет +25% к каждому счёту. Вывод — до 64 алмазов за команду.

## Ограничения прототипа
- Нарушения автоматически отслеживаются не для всех 30 указов; часть указов пока действует через игровые эффекты или объявления.
- «Карета» — условная модель на основе лошади с NPC-пассажирами, без отдельной 3D-модели повозки.
- Королевская постройка создаётся блоками, без отдельной схематики/структурного файла.
- Таймер текущего указа и активные задержания пока хранятся в памяти сервера и сбрасываются при перезапуске; банковские счета сохраняются.
- Сборка `.jar` не подтверждена в этой среде.

## Сборка
Нужны **JDK 21** и **Gradle 8.10.2 или совместимая версия**, а также интернет для загрузки зависимостей NeoForge.

В корне проекта выполни:

```bash
gradle build
```

После успешной сборки JAR появится в `build/libs/`.

## Установка
Скопируй собранный JAR в папку `mods` клиента или сервера с Minecraft 1.21.1 и NeoForge 21.1.x.

## Проверка
В этой рабочей среде Java 21 доступна, но Gradle не установлен, а доступ к внешним репозиториям недоступен. Поэтому я не могу честно заявить, что исходники прошли компиляцию или что готовый JAR протестирован.
